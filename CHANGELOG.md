## 0.7.2 - 2026-11-02

- Add `evergreen glance`, a one-screen terminal summary card of a repository's lifecycle state: the Evergreen mark on the left and, on the right, the repository name, detected ecosystems with their maturity level, findings by severity as colored blocks, the next deadline, the oldest ended item, and the data version and age, with `--as-of` and a `--json` facts document. (#1855)
- Add the `check_snippet` MCP tool and the `evergreen check-snippet --path <path>` command: before writing a file, an agent can ask what Evergreen would flag by passing the intended repository-relative path and the exact content on stdin. The snippet is written as the only file of a temporary directory, scanned with all built-in detectors, and the findings come back with paths and lines relative to the snippet; the temporary directory is always removed and the real repository is never read or written. Absolute paths, `..`, paths over 256 characters, and content over 1 MB are rejected. (#1888)
- Add a uv and PDM lockfile analyzer to `upgrade-check`: it judges the project's own Python range (top-level `requires-python` in `uv.lock`, `[metadata]` `requires_python` in `pdm.lock`) and every package's declared bounds — `resolution-markers` and version-specific wheel tags in `uv.lock`, `requires_python` and `groups` in `pdm.lock` — against the target release, reporting blockers, dev-group warnings, and unparsable values as unknowns; a package whose file states no Python bound is reported as nothing, never guessed from wheel availability. (#1863)
- Add a codemod that rewrites the Python 3.12-deprecated `datetime.utcnow()` and `datetime.utcfromtimestamp(t)` to `now(timezone.utc)` and `fromtimestamp(t, timezone.utc)` with `.replace(tzinfo=None)`, returning the same naive value, following the file's import shape; refusals for star imports, aliased or rebound names, conflicting `timezone` bindings, and multi-line imports. (#1829)
- Add a Kubernetes cluster importer to `evergreen inventory`. It reads `kubectl version -o json` for the control-plane version and `kubectl get nodes -o json` for each node's kubelet version, operating-system image, and container runtime, at the exact JSON Pointer each claim rests on. Provider suffixes (`-eks-…`, `-gke.…`, `+k3s1`) are stripped before the upstream release line is judged, and `registry/kubernetes.json` adopts the upstream minor-release rules the `kubernetes-2` lifecycle importer drafts from the Kubernetes release history page, plus a reviewed rule for the older lines. It reads only the files given to it and runs no command. (#1872)
- Promote the Go and Rust detectors to Supported after adding 97 independently reviewed corpus entries. The corpus now holds 43 Go entries (31 blind) and 78 Rust entries (53 blind); the Go detector reports all 111 expected findings and the Rust detector all 63, with no false positives or false negatives. (#1892)
