# Next.js starter kit files

Copy-paste files for the [Next.js starter kit](../../../docs/starters/nextjs.md). Drop them into a Next.js repository at the same paths, then commit an empty or reviewed `.evergreen-baseline.json`.

| Path in this directory | Destination in your project |
| --- | --- |
| `.github/workflows/evergreen.yml` | `.github/workflows/evergreen.yml` |
| `.evergreen-baseline.json` | `.evergreen-baseline.json` |
| `.cursor/mcp.json` | `.cursor/mcp.json` (merge the `evergreen` entry if you already have one) |
| `.cursor/rules/evergreen.mdc` | `.cursor/rules/evergreen.mdc` |

Live example: [arminazimi/evergreen-starter-nextjs](https://github.com/arminazimi/evergreen-starter-nextjs).
