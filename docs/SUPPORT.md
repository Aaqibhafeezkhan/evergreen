# Evergreen support

For installation problems, unexpected findings, compatibility questions, or feature requests, open a [GitHub issue](https://github.com/arminazimi/evergreen/issues). Include the Evergreen version, host, operating system, relevant manifest type, and a minimal reproduction that contains no secrets.

Security vulnerabilities should follow the repository's security reporting instructions when available. Do not post credentials, private source code, or undisclosed vulnerabilities in a public issue.

Evergreen currently supports its documented Node.js, npm, Python, GitHub Actions, and Go roadmap scope. It reports unsupported ecosystems as limitations rather than inventing lifecycle claims.
